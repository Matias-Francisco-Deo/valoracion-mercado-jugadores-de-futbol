## Summary

Develop a comprehensive automated test suite for [`ExternalPlayerWhoScoredScrapper`](file:///F:/Users/ROCKITO/Documents/Hamwork/UNQ/desurollo/overcode/valoracion-mercado-jugadores-de-futbol/backend/src/main/java/com/overcode/persistence/repository/dao/external/scrapper/whoscored/ExternalPlayerWhoScoredScrapper.java) and its underlying [`ScraperHttpClient`](file:///F:/Users/ROCKITO/Documents/Hamwork/UNQ/desurollo/overcode/valoracion-mercado-jugadores-de-futbol/backend/src/main/java/com/overcode/persistence/repository/dao/external/scrapper/http/ScraperHttpClient.java). The suite isolates all tests from live external networks by using Spring Mockito mocks (`@MockBean`) for the scraper and a local loopback `MockWebServer` (`okhttp3.mockwebserver`) for Playwright's Chromium browser. All test method names are written in Latin American Spanish, covering both happy paths and edge cases (boundary divisions, multi-league aggregation, missing JSON nodes, Cloudflare anti-bot challenge retries, and network resource aborting).
